# Al amin Physics - আধুনিক পদার্থবিজ্ঞান লার্নিং প্ল্যাটফর্ম

একটি আধুনিক, রেসপনসিভ এবং পূর্ণাঙ্গ এডুকেশনাল ওয়েব অ্যাপ্লিকেশন।

## 📁 ফাইল স্ট্রাকচার
- `index.html` : মূল ওয়েব অ্যাপ্লিকেশন ইন্টারফেস
- `style.css` : কাস্টম স্টাইলিং ও গ্লাস মরফিজম ডিজাইন
- `app.js` : সকল অধ্যায়, মডিউল, সিমুলেশন, পরীক্ষা ও পেমেন্ট লজিক
- `README.md` : ডকুমেন্টেশন

## 🚀 যেভাবে চালাবেন (How to Run)
1. এই ফোল্ডারের `index.html` ফাইলটির ওপর ডাবল ক্লিক করুন।
2. আপনার পছন্দের যেকোনো ওয়েব ব্রাউজারে (Google Chrome, Microsoft Edge) সরাসরি এটি চালু হয়ে যাবে।

## ✨ মূল ফিচারসমূহ
1. **নবম-দশম শ্রেণি**: এনসিটিবি (NCTB) সিলেবাসের ১৩টি অধ্যায়।
2. **একাদশ-দ্বাদশ শ্রেণি**: 
   - ১ম পত্র (১০টি অধ্যায়)
   - ২য় পত্র (১১টি অধ্যায়)
3. **অষ্টম বিজ্ঞান**: পদার্থবিজ্ঞান সংশ্লিষ্ট ৮টি অধ্যায়।
4. **১০টি কোর মডিউল**:
   - বেসিক
   - ভিডিও ক্লাস
   - সূত্রসমূহ
   - গাণিতিক (লাইভ ফিজিক্স ক্যালকুলেটর সহ)
   - অনুধাবনমূলক (খ প্রশ্ন)
   - বোর্ড প্রশ্ন
   - ভার্চুয়াল ল্যাব ও সিমুলেশন (ক্যানভাস ভিত্তিক)
   - জিজ্ঞাসা (Q&A ফোরাম)
   - ফ্রি পরীক্ষা (টাইমার ও ইনস্ট্যান্ট রেজাল্ট সহ)
   - অধ্যায়ভিত্তিক পেইড কোর্স (বিকাশ/নগদ পেমেন্ট ও এনরোলমেন্ট)
5. **রোল বেসড সিস্টেম**: স্টুডেন্ট, টিচার, এডমিন এবং ডিরেক্টর ড্যাশবোর্ড মোড।
